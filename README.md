# IMG_LABS (photoshop-ElfMmmk)

Демо: https://elfmmmk.github.io/img_lab/

## О проекте
Веб-приложение для загрузки и визуализации изображений (PNG/JPG и учебный формат GrayBit-7) с отрисовкой на `<canvas>`, статус-баром (ширина/высота/глубина цвета), масштабированием и инструментами.

## Технологии
- JS + HTML5 Canvas
- Webpack
- (опционально) GitHub Pages для хостинга

## Запуск локально
```bash
npm ci
npm run build
